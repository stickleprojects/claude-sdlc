## New: `make local-check`, the local check before a PR

The build skill, the build template, the verifier and the review-findings and identity skills now run `make local-check` instead of `make check` and `make coverage` (#253). With nothing set, it runs what they ran before: `make check`, then `make coverage` if your Makefile has it. Its last line says whether coverage ran (`coverage: ran`), is left to CI (`coverage: in CI`), or has no target (`coverage: none`). build.md's status and the PR body repeat it.

The target arrives with the sync, in `.sdlc/sdlc.mk`; your Makefile doesn't change. A build.md written before this keeps its `make check` and `make coverage` Done-when lines until its next session brings it up to date from the template.

## Optional: a lighter local check

Add a `Local check:` line to your CLAUDE.md to choose what runs on the laptop, for example `Local check: preflight`. Then `make local-check` runs only the targets the line names, and coverage runs locally only if the line names it (`Local check: preflight coverage`); otherwise the PR's CI runs it. A green local check then means only what the line names passed, not the full suite, so pair it with `SDLC_PR_CHECK_TARGET` and main's `make check FULL=1`. A name the Makefile doesn't define fails `make validate`, naming the line. `.sdlc/docs/settings.md` has the details.

A repo that overrode the build skill, the build template or the verifier in `.sdlc-local/` to run a lighter check can set the line and delete those overrides.
