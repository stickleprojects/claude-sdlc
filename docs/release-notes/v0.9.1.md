## Upgrade steps

These are for Claude, as part of `/sdlc`. Do them with the person, after the sync and before `make check`.

1. **Let the sync's `/build` files through `.gitignore` (in the sync PR).** The baseline `.gitignore` had a bare `build/` line, which also ignored `.claude/skills/build/`. A file a sync added there was never staged, so the sync PR silently left it out (#114). Run:

   ```
   scripts/bootstrap-github.sh --gitignore-only
   ```

   It needs no GitHub access. It appends `!.claude/skills/build/` after the repo's existing `build/` line, along with any other baseline line that's missing. Then check that nothing under the skill folder is still ignored:

   ```
   git check-ignore .claude/skills/build/*
   ```

   That command should print nothing. Then run `git status`: a file this or an earlier sync added under `.claude/skills/build/` may now show as untracked. Stage it, along with `.gitignore`, in the sync PR. A repo that never ran bootstrap, or that has no `build/` line, needs no change.

2. **Retry the agent App, only if creating it failed.** `scripts/agent-identity.sh create` used to fail on GitHub's *Create GitHub App* page with "Hook url is not supported because it isn't reachable over the public Internet (127.0.0.1)" (#115). Ask the person whether that happened here. If it did, they can now run `scripts/agent-identity.sh create` again, then `scripts/agent-identity.sh check`. They run these themselves, because creating the App needs their browser and their GitHub account. A repo whose App already works needs nothing.
