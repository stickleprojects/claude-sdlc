## New: `/sdlc` to update the pipeline

Projects now have a skill for the pipeline itself. Run `/sdlc` in Claude Code to see which claude-sdlc version you're on and what's new since. It lists breaking changes first, then optional features, and says whether your repo already uses each one. It then syncs on a branch, works through any merge conflicts and missing `make` targets with you, runs `make check` and opens the sync PR for you to merge. `/next` also tells you when a newer release is out.

**One last sync by hand.** Your project doesn't have `/sdlc` until it syncs to this release, so run this sync yourself:

```
git switch -c chore/sync-sdlc-v0.6.0 origin/main
make sync-sdlc REF=v0.6.0
make check
```

Commit, push and open the PR as the sync's output says. From the next release on, run `/sdlc` instead.

Coming from v0.4.0 or earlier? v0.5.0 added optional architecture decision records (ADRs) and the `.sdlc.toml` placeholder words. Its [release notes](https://github.com/stickleprojects/claude-sdlc/releases/tag/v0.5.0) explain how to adopt them.
