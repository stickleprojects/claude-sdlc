# Plan: the whole castle in the data

Spec: ./spec.md

## Approach

Floors are generated by rule from `data/floors.json`. The warp list shows two levels: the floor group, then the floors in it, so a long castle still fits on screen.

## Steps

1. Generate every floor from the floor rules.
2. Build the two-level warp list from the warp points.
